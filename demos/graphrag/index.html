Data provenance & implementation notes

The selected network and stored parent–child memberships come from actual UAV experiment exports. The weighted force-directed coordinates are newly calculated for this visualizer, not a native GraphRAG output. Extraction event order is reconstructed from final source lists; internal Leiden local-moving events were not logged. The animated greedy modularity moves use the recorded Edge Weights but are newly recomputed illustrative assignment steps, not the original Leiden execution log. Visual node motion follows assignments for explanation only. The saved Community hierarchy is real experimental output. V11 additionally illustrates repeated local moving, refinement, and temporary aggregation on real induced parent subgraphs; these are newly calculated educational examples, not the original Leiden internal traces. Source implementation: raglab/graph.py, vendor/microsoft/cluster_graph.py.
